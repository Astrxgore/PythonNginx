# Неочевидные вещи в проекте

Этот файл можно читать перед защитой. Здесь собраны решения, которые легко пропустить, но по ним часто задают вопросы.

## Почему `asyncio`, а не потоки

HTTP-сервер много ждет: данные из сети, отправку ответа, ответ upstream. `asyncio` позволяет одному потоку переключаться между соединениями во время таких ожиданий.

Это не делает CPU-вычисления быстрее, но хорошо подходит для I/O-задач.

## Почему HTTP разбирается вручную

В задаче это отдельное требование. Поэтому не используются `aiohttp`, `h11`, `uvicorn`.

Парсер сам:

- читает до `\r\n\r\n`;
- разбирает request line;
- разбирает headers;
- проверяет `Host`;
- проверяет `Content-Length`.

## Почему читаем только до `\r\n\r\n`

Для `GET` и `HEAD` тело запроса не нужно. Если читать больше, сервер может зря ждать данные или тратить память.

Для proxy тело читается отдельно через `Content-Length`, потому что его нужно переслать upstream.

## Почему важен `Content-Length`

При keep-alive одно TCP-соединение содержит несколько HTTP-ответов подряд. Клиент должен понять, где заканчивается первый ответ.

Самый простой способ - всегда отправлять `Content-Length`.

## Почему headers хранятся в lower-case

HTTP-заголовки регистронезависимы:

```text
Host
host
HOST
```

Это один и тот же заголовок. Поэтому при парсинге ключи приводятся к lower-case.

## Почему `Host` обязателен для HTTP/1.1

На одном IP и порту может быть несколько сайтов. Сервер выбирает virtual host по `Host`.

В HTTP/1.1 клиент обязан отправлять `Host`.

## Почему directory URL без `/` получает redirect

Если открыть каталог как `/files`, относительные ссылки внутри autoindex будут считаться от `/`, а не от `/files/`.

Поэтому сервер отвечает `301 Location: /files/`.

## Что такое path traversal

Опасный запрос:

```text
/../secret.txt
```

Если просто склеить `root + path`, можно выйти из public-директории.

Защита:

```python
candidate = (root / relative).resolve()
if root != candidate and root not in candidate.parents:
    return 403
```

`.resolve()` превращает путь в нормальный абсолютный путь, убирая `..`.

## Зачем `html.escape`

Autoindex вставляет имена файлов в HTML. Если файл называется `<script>.txt`, без escaping браузер может воспринять это как HTML.

`html.escape()` превращает опасные символы в безопасные HTML-сущности.

## Почему proxy удаляет hop-by-hop headers

Некоторые headers относятся только к одному соединению, а не к запросу вообще:

- `Connection`;
- `Keep-Alive`;
- `Transfer-Encoding`;
- `Upgrade`.

Reverse proxy не должен слепо передавать их дальше, потому что соединение клиент-сервер и соединение сервер-upstream разные.

## Почему upstream получает `Connection: close`

Это упрощает proxy. Серверу не нужно держать пул соединений к upstream и следить за их состоянием.

Минус: на каждый proxy-запрос открывается новое TCP-соединение. Для учебной задачи это нормально.

## Почему open file cache хранит fd

Обычная отдача файла делает:

```text
stat -> open -> read -> close
```

Для популярных файлов это повторяется много раз. Кэш хранит открытый fd и метаданные файла.

Если файл не изменился, сервер читает через тот же fd. Если изменился, старый fd закрывается и открывается новый.

## Почему используется `os.pread`

`os.read(fd, size)` двигает текущую позицию fd. Если один fd используется повторно, позиция может мешать следующим чтениям.

`os.pread(fd, size, offset)` читает с указанного offset и не меняет позицию fd.

## Почему file read вынесен в `asyncio.to_thread`

Обычное чтение файла с диска блокирующее. `asyncio.to_thread()` выполняет такую функцию в отдельном рабочем потоке, чтобы event loop мог продолжать обслуживать другие соединения.

## Почему есть лимиты

Лимиты защищают сервер:

- `header_limit` - от огромных заголовков;
- `body_limit` - от слишком большого тела;
- `keepalive_timeout` - от молчащих клиентов;
- `keepalive_max_requests` - от бесконечного удержания одного соединения.

## Почему chunked body не поддержан

Chunked encoding требует отдельного парсера чанков. Для учебной версии достаточно `Content-Length`.

Сервер честно возвращает `501 Not Implemented`, если клиент прислал неподдерживаемое тело.
